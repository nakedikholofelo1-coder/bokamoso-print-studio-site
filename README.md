# Bokamoso Print Studio

A playful, responsive one-page website for Bokamoso Print Studio in Johannesburg.

## Run locally

Open `index.html` in a browser. The site is a static HTML page with inline CSS and JavaScript; no build step is required.

## Deploy

The project is configured for static hosting on Vercel. Set the project root to this repository and leave the build and output directory settings blank.
